## Мультиплексор 10→1 на базе каскада MUX 4→1

Модель изделия — мультиплексор на 10 информационных входов (d0–d9)
с 4 адресными линиями (a3–a0). Реализован каскадом из четырёх
мультиплексоров 4→1.

Для адресов 10–15 выход принудительно равен 0 (неиспользуемые адреса).
Вход EN отсутствует.

## Структура проекта

 `mux4to1.py` - модель одного мультиплексора 4→1 
 `mux10to1.py` - модель изделия 
 `mux_tests.py` - тесты 
 `main.py` - запуск 

## Запуск

**Требования:** Python 3.14

2. Открыть `main.py`:

   python main.py
